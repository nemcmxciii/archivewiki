====== A place to keep what matters ======

Keep notes, useful details, family stories, and sources you want to find again. Your wiki is stored on this Mac. Start with one small thing; you can organize it later.

===== Recent pages =====

Pages you open appear here, newest first. This list is stored only on this Mac.

===== Find or add a page =====

Enter a title to create a page or open one with that title. To search the words inside your pages, choose **View → Search Archive** (⌘K). You can write in plain sentences; no special formatting is needed.

===== Keep a copy =====

Automatic daily backups are on by default and run while ArchiveWiki is open. To make a backup now, choose **File → Back Up & Restore → Back Up Now**. For an additional copy, save a backup to another drive.
