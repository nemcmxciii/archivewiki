====== ArchiveWiki ======

Your private archive, stored on this Mac.

**Back it up regularly.** Use **File → Back Up Wiki…** for a backup, or **File → Create Archive Snapshot…** to create a snapshot with file checksums. Keep a copy somewhere separate from this Mac.

===== Capture =====

  * **File → New Note** (⇧⌘N) opens a timestamped note in the Journal.
  * **File → Today's Journal Entry** (⇧⌘J) opens today's journal page.

===== Browse your archive =====

  * [[journal:start|Journal]] — dated entries and notes
  * [[genealogy:start|Genealogy]] — family and research subjects
  * [[portfolio:start|Portfolio]] — residential, employment and credentials history
  * [[reference:start|Reference]] — sources, links and documents

===== Find or add a page =====

Use **View → Search Archive** (⌘K) to search your pages. To add a page, link to it (for example ''%%[[genealogy:jane_doe]]%%''), then click the link and choose **Create this page**.

Add direct links to a few pages you return to often, if useful. This page does not show a list of recent page titles.
